# Einstellungen – Katalog

App-Name: **Launcher TOS**. Grundsatz: Fast alles ist einstellbar,
aber die Standardwerte funktionieren ohne Einrichtung. Jede Seite hat eine Live-Vorschau
und „Auf Standard zurücksetzen“. Eine Suche über alle Einstellungen gibt es oben auf der
Startseite der Einstellungen.

Legende: **P1** = Phase 1, **P2** = Phase 2, **P3** = später

## 1. Homescreen & Raster
| Einstellung | Werte | Phase |
|---|---|---|
| Spalten | 3–7 (Standard 4) | P1 |
| Reihen | 4–9 (Standard 6) | P1 |
| Seitenrand links/rechts | 0–32 dp | P1 |
| Abstand oben/unten | 0–48 dp | P2 |

| Endlos blättern (letzte → erste Seite) | an/aus | P2 |

| Layout sperren (kein versehentliches Verschieben) | an/aus | P1 |
| Statusleiste ausblenden | an/aus | P2 |

## 2. App-Icons
Im Launcher werden immer die **Original-Icons** der installierten Apps gezeigt.
Einstellbar ist nur, wie sie dargestellt werden.

| Einstellung | Werte | Phase |
|---|---|---|
| Rundung der Maske | 0–100 % (Squircle, Live-Vorschau) | P1 |
| Icongröße | 70–130 % | P1 |
| Schatten | aus / leicht / stark | P2 |
| Legacy-Icons (nicht-adaptiv) | Hintergrund weiß / Farbe aus Icon / eigene Farbe; Icon verkleinern | P1 |
| Themen-Icons (Android 13+, einfarbig) | an/aus | P2 |
| Icon-Pakete aus dem Play Store | Auswahl, pro App überschreibbar | P3 |
| Einzelnes Icon/Namen ändern | lange drücken → Bearbeiten | P2 |

## 8. Gesten
Jede Geste lässt sich frei belegen: Benachrichtigungen, Schnellzugriff, Suche,
App-Übersicht, App öffnen, Assistent, Bildschirm sperren*, nichts.

| Geste | Standard | Phase |
|---|---|---|
| Wisch von oben links | Benachrichtigungen | P2 |
| Wisch von oben rechts | Schnellzugriff | P2 |
| Wisch nach unten (Mitte) | Suche | P2 |
| Wisch nach oben | nichts / App-Übersicht | P2 |
| Doppeltipp auf leere Fläche | nichts | P2 |
| Doppeltipp unten | Assistent (Standard-Assistent von Android) | P2 |
| Zwei-Finger-Zoom | Seitenübersicht | P3 |
| Breite des Wisch-Bereichs oben | 20–50 % je Seite | P2 |

\* „Bildschirm sperren“ braucht einen Bedienungshilfe-Dienst und ist deshalb optional.

## 16. Datenschutz & Berechtigungen
Übersicht jeder Berechtigung mit kurzer Erklärung und Schalter zum Widerrufen:
Benachrichtigungszugriff (Badges, Benachrichtigungsliste, Medien),
Nicht-stören-Zugriff, Systemeinstellungen ändern (Helligkeit, Drehsperre), optional
Bedienungshilfe. Keine Internetberechtigung, kein Tracking.
